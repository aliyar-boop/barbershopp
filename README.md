# Golden Cut — Barbershop Booking

Адаптивдүү, кара-алтын түстөгү барбершоп демо-сайты. React жана Vite менен иштейт; Firebase, сервер же интернеттеги маалымат базасы колдонулбайт. Кызматтар, барбер, колдонуучулар, билдирмелер жана жазылуулар браузердин `localStorage` сактагычында сакталат.

## Иштетүү

```sh
npm install
npm run dev
```

`.env.example` файлындагы `VITE_SHOP_PHONE` жана `VITE_SHOP_ADDRESS` маанилерин кааласаңыз `.env.local` файлына көчүрүп, дүкөндүн байланыш маалыматын көрсөтүңүз. Демонстрация үчүн Firebase конфигурациясы талап кылынбайт.

## Демо аккаунттар

- Админ: `/admin` дарегине өтүп, `Aliar` сөзүн киргизиңиз.
- Кардар: `customer@goldencut.demo` / `demo123456`.
- Барбер: `barber@goldencut.demo` / `demo123456`.

Админ кызматтарды жана барберди кошуп, өзгөртүп же өчүрө алат; бааларды, узактыкты жана барбердин иш графигин башкарат; кардарлардын жазылууларын көрүп, ырастап, жокко чыгарып же өчүрөт.

## Демо маалымат жана сактоо

Биринчи ачылышта беш кызмат, бир барбер жана үч мисал жазылуу автоматтык кошулат. Кызматтардын баштапкы баасы такталбагандыктан бош бойдон калат; админ панелинен баа киргизүүгө болот. Жаңы жазылуулар кызмат/барбер графигин жана убакыттардын кесилишпешин текшерип, `localStorage` ичинде сакталат. Жазылууларды демо кардар жана демо барбер аккаунттары аркылуу көрүүгө болот.

Бул презентация үчүн гана жасалган демо: аккаунттар жана админ сырсөзү браузерде иштетилет, алар коопсуздук чеги эмес жана чыныгы кардар маалыматтары үчүн колдонулбашы керек. Маалымат браузердин сайт сактагычын тазалаганда өчөт жана башка түзмөккө автоматтык синхрондолбойт.
